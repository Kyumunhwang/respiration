# 교사용 '호흡' 시뮬레이션 조작 가이드 및 수업 활용 시나리오

> **대상 학년 및 성취기준:** 중학교 2학년 과학 [생물의 호흡과 배설] 단원 `[9과11-03]` 호흡계의 구조와 기능을 알고, 호흡 운동의 원리를 설명할 수 있다.  
> **권장 수업 환경:** 교실 전자칠판(16:9 와이드 스크린 `1280×720` / `1920×1080`) 및 학생용 태블릿(`1024×768`) — **스크롤 없는 한 화면 수업 최적화**

## 1. 프로젝트 실행 방법

### ① 오프라인 교실 환경 (인터넷·서버 없이 바로 실행)
1. 프로젝트 빌드가 완료된 `dist/index.html` 파일을 찾습니다. (최초 1회 생성 필요 시 터미널에서 `npm.cmd run build` 실행)
2. `dist/index.html` 파일을 **Chrome** 또는 **Microsoft Edge** 브라우저로 더블 클릭(또는 드래그)하여 바로 엽니다.
3. `vite-plugin-singlefile` 단일 번들로 구성되어 있어 외부 CDN·인터넷 연결 없이도 전자칠판 및 USB 배포 환경에서 100% 정상 작동합니다.

### ② 개발 서버 및 미리보기 서버 실행 (수업 전 점검·커스터마이징용)
작업 폴더(`D:\Respiration_simulation`)에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
# 개발 서버 실행 (포트 3420 고정)
npm.cmd run dev:respiration-sim
```
- 브라우저에서 **`http://localhost:3420`** 으로 접속합니다.

프로덕션 빌드 결과물을 로컬 서버로 미리 확인하려면 다음 명령을 사용합니다.
```powershell
npm.cmd run build
npm.cmd run preview:respiration-sim
```
- 브라우저에서 **`http://localhost:3421`** 으로 접속합니다.

## 2. 전체 화면 구성 및 4개 탭별 상세 조작법

시뮬레이션 화면은 전자칠판에서 한눈에 들어오도록 **4단 구조**로 배치되어 있습니다.

1. **상단 헤더 바:** 4개 핵심 학습 탭 전환 + **`오개념 형성평가 퀴즈`** 모달 실행 버튼
2. **교사용 제어 바 (`TeacherControlBar`):** 블라인드 퀴즈(`?` 가리기) 제어 + 6단계 스텝별 수업 모드 제어 + 현재 탭의 **핵심 발문** 및 **예상 오개념** 요약 팁
3. **메인 실험실 캔버스:** 선택한 탭의 해부도·물리 시뮬레이션·페트병 모형·폐포 확산 시각화 영역
4. **하단 6단계 인과관계 플로우 바:** `[갈비뼈·횡격막 움직임] → [흉강 부피] → [흉강 압력] → [폐 부피] → [폐 내부 압력] → [공기 이동]` 실시간 연동 표시기

---

### [탭 1] 호흡계의 구조와 기능
* **주요 조작법:**
  * 왼쪽 인체 호흡계 도식에서 **코(비강), 기관, 기관지, 폐, 폐포**를 터치/클릭하면 해당 기관이 강조 표시됩니다.
  * 오른쪽 패널에 기관의 핵심 역할, 세부 기능, **현미경/단면 갤러리 일러스트**(`비강 점막·코털`, `기관 말굽 모양 연골 고리·섬모`, `폐포 다발·모세혈관 그물망`, `폐포 단면·기체 확산`)가 즉시 연동되어 나타납니다.
* **전자칠판 판서 및 발문 팁:**
  * **기관의 말굽(C자) 모양 연골 고리:** *"기관이 부드러운 살로만 되어 있다면 숨을 세게 들이쉴 때 어떻게 될까요?"* (빨대를 세게 빨 때 납작해지는 현상과 비교 판서)
  * **입 호흡 vs 코 호흡:** *"겨울철 차가운 공기를 입으로 계속 들이마시면 목이 금방 칼칼해지는 이유는 무엇일까요?"* (비강의 코털·점액·모세혈관에 의한 여과·가온·가습 기능 연결)

---

### [탭 2] 호흡 운동의 원리 (인체)
* **주요 조작법:**
  * **호흡 단계 슬라이더:** `날숨 최대 ↔ 평상시 ↔ 들숨 최대` 구간을 손가락이나 마우스로 천천히 드래그하여 갈비뼈의 회전 상승/하강과 횡격막 곡률 변화를 정지 화면으로 관찰합니다.
  * **자동 호흡 재생 모드:** **평상시 호흡(분당 15회, 15 BPM)** 과 **운동 후 빠른 호흡(분당 32회, 32 BPM)** 버튼을 전환하여 호흡 깊이와 속도의 차이를 비교합니다.
  * **실시간 물리량 및 기류 입자:** 기준 대기압 `760 mmHg` 대비 흉강 부피(`2,500~3,500 mL`), 흉강 압력, 폐 내부 압력이 **보일의 법칙($P \propto 1/V$)** 에 따라 실시간 갱신되며, 압력 차가 발생할 때만 들숨(청록 `#00B4D8`) / 날숨(주황 `#F4A261`) 공기 입자가 이동합니다.
* **전자칠판 판서 및 발문 팁:**
  * **폐의 수동성 원칙(가장 중요):** *"폐 자체에는 근육이 전혀 없습니다! 근육이 없는 폐가 어떻게 커지고 작아질 수 있을까요?"* → 반드시 **갈비뼈·횡격막 움직임 → 흉강 부피·압력 변화 → 폐의 수동적 크기 변화** 순서를 화살표로 판서하세요.
  * 들숨 최대 지점에서 슬라이더를 멈춘 뒤 *"지금 횡격막은 올라갔나요, 내려갔나요?"*를 질문해 반대 방향(갈비뼈 ▲, 횡격막 ▼)을 시각적으로 각인시킵니다.

---

### [탭 3] 페트병 호흡 모형 비교
* **주요 조작법:**
  * **고무막 손잡이 드래그:** 페트병 바닥의 고무막 손잡이를 직접 아래로 당기거나 위로 밀어 올리면, 내부 공간 압력 변화에 따라 Y자관 끝의 고무풍선이 수동적으로 부풀고 줄어듭니다.
  * **인체 흉곽 나란히 비교:** 왼쪽의 페트병 모형과 오른쪽의 인체 흉곽이 실시간으로 동기화되어 움직입니다.
  * **1:1 구조 대응 및 한계점 패널:** `Y자관`, `고무풍선`, `페트병 벽면`, `고무막`, `페트병 내부 공간` 중 하나를 클릭하면 대응되는 인체 구조(`기관·기관지`, `폐`, `흉강 벽(갈비뼈)`, `횡격막`, `흉강`)가 하이라이트되고 역할과 한계점이 표시됩니다.
* **전자칠판 판서 및 발문 팁:**
  * **시험 빈출 한계점 강조:** **`페트병 벽면 ↔ 흉강 벽(갈비뼈)`** 항목을 클릭한 뒤 *"실제 우리 몸의 갈비뼈는 숨을 들이쉴 때 위·바깥쪽으로 들려 올라가지만, 딱딱한 플라스틱 페트병 벽면은 움직일 수 있을까요?"*라고 발문하세요.
  * 고무풍선 입구로 바람을 불어넣는 것이 아니라 **고무막을 당겨 내부 압력을 낮추기 때문에** 공기가 들어온다는 점을 강조합니다.

---

### [탭 4] 폐포의 구조와 기체 교환
* **주요 조작법:**
  * **표면적 비교 실험기:** 동일한 전체 부피($V$ 일정)를 유지한 상태에서 분할 수($N$)를 늘려 `단일 큰 구(폐포 1개)`와 `수많은 작은 폐포 다발`의 전체 겉넓이(표면적, $S \propto N^{1/3}$) 변화를 수치와 시각 자료로 비교합니다.
  * **분압 차 확산 애니메이션:** 폐포 내 공기($O_2$ 높음 약 `104 mmHg`, $CO_2$ 낮음 약 `40 mmHg`)와 폐동맥 쪽 정맥혈($O_2$ 낮음 약 `40 mmHg`, $CO_2$ 높음 약 `45 mmHg`) 사이에서 기체가 **분압이 높은 곳에서 낮은 곳으로 확산**하며 폐정맥 쪽 동맥혈($O_2$ 약 `100 mmHg`, $CO_2$ 약 `40 mmHg`)의 적혈구가 선홍색으로 변하는 과정을 관찰합니다.
* **전자칠판 판서 및 발문 팁:**
  * *"산소와 이산화탄소는 에너지(ATP)를 쓰거나 심장이 밀어주지 않아도 왜 정확히 반대 방향으로 이동할까요?"* → 각 기체의 **분압(높음 → 낮음)** 수치를 전자칠판에서 동그라미 치며 화살표로 연결해 주세요.

## 3. 교사용 수업 보조 도구 활용법

### ① 블라인드 퀴즈 (`?` 가리기) 모드
* **켜기/끄기:** 제어 바의 **`블라인드 퀴즈 ON/OFF`** 버튼을 누릅니다.
* **작동 대상:** 호흡계 구조의 기관 명칭과 하단 6단계 인과관계 플로우 바의 방향(▲/▼) 및 핵심 키워드가 노란색 **`?`** 배지로 가려집니다.
* **수업 활용:**
  1. **`모두 가리기(?)`** 로 전체를 가린 뒤 학생들에게 질문합니다.
  2. 발표자가 정답을 말하면 해당 **`?`** 배지만 개별 터치/클릭하여 부분 공개합니다.
  3. 정리가 끝나면 **`모두 공개`** 를 눌러 전체 정답을 한 번에 확인합니다.

### ② 6단계 스텝별 멈춤 수업 모드 (Step-by-Step)
* **시작하기:** **`들숨 6단계 수업`** 또는 **`날숨 6단계 수업`** 버튼을 클릭합니다.
* **단계 이동:** **`◀ 이전 단계`** / **`다음 단계 ▶`** 버튼으로 `1/6`부터 `6/6`까지 한 단계씩 순서대로 점등하며 설명합니다. (수업 모드를 끝낼 때는 **`단계 모드 종료`** 클릭)
* **인과관계 6단계 기준표:**

| 단계 | 구분 | 들숨 (흡기) | 날숨 (호기) | 수업 강조 포인트 |
| :---: | :--- | :--- | :--- | :--- |
| **1/6** | 갈비뼈·횡격막 움직임 | 갈비뼈 **상승(▲)** · 횡격막 **하강(▼)** | 갈비뼈 **하강(▼)** · 횡격막 **상승(▲)** | 두 구조가 반대 방향으로 움직임 |
| **2/6** | 흉강 부피 | 흉강 부피 **증가(▲)** | 흉강 부피 **감소(▼)** | 흉강 공간이 먼저 변함 |
| **3/6** | 흉강 압력 | 흉강 압력 **감소(▼)** | 흉강 압력 **증가(▲)** | 보일의 법칙 ($P \propto 1/V$) |
| **4/6** | 폐 부피 | 폐 부피 **증가(▲)** | 폐 부피 **감소(▼)** | 폐는 근육이 없어 수동적으로 변함 |
| **5/6** | 폐 내부 압력 | 폐 내부 압력 **감소(▼, 대기압보다 낮음)** | 폐 내부 압력 **증가(▲, 대기압보다 높음)** | 기준 대기압 약 `760 mmHg`와 비교 |
| **6/6** | 공기 이동 | 외부 공기가 **폐로 유입** | 폐 내부 공기가 **외부로 유출** | 압력 높은 곳 → 낮은 곳 이동 |

### ③ 오개념 6문항 형성평가 퀴즈 모달
* 상단 헤더의 퀴즈 버튼을 누르면 전자칠판용 대형 **`O / X`** 버튼 및 **`4지 선다 / 직접 입력`** 빈칸 채우기 모달이 열립니다.
* 문항별 즉각 정답/오답 피드백과 상세 해설, 핵심 개념 태그, 실시간 점수가 제공되며 마지막 결과 요약 화면에서 **`다시 풀기`** 로 반별 반복 평가가 가능합니다.

## 4. 중2 과학 핵심 오개념 6가지 & 정답/해설 요약표

| 번호 | 유형 | 문항 내용 | 정답 | 핵심 개념 | 정답 해설 요약 |
| :---: | :---: | :--- | :---: | :--- | :--- |
| **1** | OX | 폐는 스스로 근육이 있어 수축하고 이완한다. | **X** | 폐의 수동성 원칙 | 폐 자체에는 근육이 없어 스스로 움직이지 못하며, 갈비뼈와 횡격막 움직임에 따른 흉강 압력 변화로 수동적으로 부풀거나 줄어듭니다. |
| **2** | OX | 들숨이 일어날 때 횡격막은 위로 올라간다. | **X** | 들숨 시 횡격막과 갈비뼈의 방향 | 들숨 시 갈비뼈는 위로 올라가고(상승) 횡격막은 아래로 내려가야(하강) 흉강 부피가 커지고 압력이 낮아져 공기가 들어옵니다. |
| **3** | OX | 페트병 호흡 모형에서 단단한 페트병 벽면은 실제 인체의 갈비뼈처럼 상하좌우로 움직여 내부 부피를 변화시킬 수 있다. | **X** | 페트병 호흡 모형의 한계점 | 페트병 벽면은 딱딱한 플라스틱으로 고정되어 있어 실제 갈비뼈처럼 움직여 내부 부피를 변화시키지 못합니다. |
| **4** | 빈칸 | 폐는 수많은 작은 주머니 모양의 폐포로 나뉘어 있어 공기와 닿는 `[ ___ ]`을(를) 극대화하여 기체 교환을 효율적으로 수행한다. | **표면적** | 폐포 구조와 표면적 극대화 | 동일한 부피라도 수억 개의 작은 폐포로 나뉘면 공기와 모세혈관이 맞닿는 표면적이 폭발적으로 넓어져 기체 교환 효율이 높아집니다. |
| **5** | 빈칸 | 들숨이 일어날 때 흉강 부피가 커지면 폐 내부 압력이 외부 대기압보다 `[ ___ ]` 공기가 폐 속으로 들어온다. | **낮아져** | 들숨 시 압력 차와 공기 이동 | 흉강 부피 증가 → 흉강 압력 감소 → 폐 부피 증가 → 폐 내부 압력 감소 순으로 진행되어 대기압(760 mmHg)보다 낮아지면 공기가 유입됩니다. |
